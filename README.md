# Mani Chandra Edara — Linux | AWS | DevOps Portfolio

A one-page portfolio for Mani Chandra Edara, an aspiring Linux and DevOps Engineer, focused on Linux administration, AWS cloud infrastructure, and CI/CD automation.

## Sections

- **Hero** — Name, "Linux | AWS | DevOps Engineer" title, and a short introduction.
- **About Me** — Linux administration, cloud infrastructure, automation, CI/CD, and deployment.
- **Technical Skills** — Linux, Bash, AWS (EC2, VPC, IAM, S3), networking, Git, GitHub, Jenkins, Maven, Docker, GitHub Actions, and CI/CD.
- **Featured Projects** (hands-on)
  - **AWS VPC Infrastructure** — Public/private subnets, Internet Gateway, NAT Gateway, route tables, and EC2 connectivity.
  - **Patient Order CI/CD** — GitHub Actions and Docker, with AWS ECR integration.
  - **Jenkins Automation** — Java application built with Maven through Jenkins build/deployment workflows.
- **Learning Journey** — Infrastructure configuration, troubleshooting, version control, and deployment.
- **Contact** — [github.com/Chandra73820](https://github.com/Chandra73820)

## Tech stack

- [Next.js](https://nextjs.org) (App Router) and React
- TypeScript
- Tailwind CSS
- [lucide-react](https://lucide.dev) icons

## Design

Dark charcoal background, electric blue (`#3B82F6`) accents, subtle blue gradients, Geist typography, and a responsive mobile-first layout with accessible navigation.

## Getting started

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Deployment

The site is ready to deploy on [Vercel](https://vercel.com).
